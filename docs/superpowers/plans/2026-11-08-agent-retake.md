# Agent Retake v1 Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development with operator consent or superpowers:executing-plans for native execution. Steps use checkbox syntax for tracking.

**Goal:** An agent working from chat can turn a saved research conversation into reviewed, narration-paced clips that composite directly in DaVinci Resolve Free on Linux.

**Architecture:** Four read-only adapters feed one versioned conversation model. A typed storyboard and an independent recheck of scan results produce a sanitized scene. Only that scene crosses into the seekable browser renderer. Preview and final export share the same gate and clock.

**Tech stack:** Python 3.11+, uv, argparse, typed Python models, safe YAML, Python Playwright with Chromium, local FFmpeg/ffprobe, optional faster-whisper. Use the standard library for discovery, hashing, ordering and cue scoring. Audit dependency pins before installation.

**Spec:** [Approved product design, public engineering edition](../specs/2026-11-05-agent-retake.md). The original operator design and acceptance material stay outside this repository.

## Global constraints

- Distribution `agent-retake`, executable `retake`. Run from checkout with `uv run retake`. Test a local wheel before documenting the eventual PyPI invocation `uvx --from agent-retake retake`. Registry publication is a separate release.
- Private transcripts, normalized sessions, scan strings, storyboards with real cues, editor previews, narration, model weights and footage stay outside the public checkout. Commit synthetic fixtures only. Inspect staged paths, content, commit identity and distribution contents before sharing. Configure production paths in the consuming project.
- One local operator runs file-producing commands. Treat stored transcript text and tool output as untrusted data, with no execution, remote embeds or retrieval of referenced files. Scan and human judgment cover different risks. Keep the skill's outline, redaction and preview checkpoints.
- Default 1920×1200 at 30 fps, silent ProRes 4444 alpha MOV. Optional *additional* opaque 3840×2160 DNxHR HQ MOV. Preserve the two-second tail within the beat duration. Keep output naming configurable including beat, shot and take.
- Neutral dark fixed-size window, transparent outside and rounded corners, no shadow, bottom-following overflow. CSS/config controls chrome, font and each harness identity. The later visual-design round can replace these without modifying the clock or parser.
- Keep real audio and word timestamps local. No paid runtime, no cloud transcription, no Remotion. No direct Resolve automation or production repository changes in this implementation.

## Review focus

1. Copies, live append tails, repeated identical messages and parallel sessions must preserve IDs and ordering. Pin in tasks 1 and 3.
2. Missing subagent parents, branching and duplicate event streams must neither fabricate parentage nor inflate activity counts. Pin in tasks 1 and 3.
3. A stale or incomplete scan, extra visible strings and markup-shaped tool output must never produce an unreviewed frame, HTML file or diagnostic containing the secret. Pin in tasks 2 and 4.
4. Typing, tails, cue ambiguity, layout overflow and backward seeks must behave the same in preview and export. Pin in tasks 4 and 6.
5. Encoder failure, wrong pixel formats and dark halos must be detectable. Preserve prior takes on failure. Pin in task 5 and confirm the composite in task 7.

## Verification that informs the build

- **Claude Code.** Local read-only sampling found UUIDs, block arrays, assistant tool-use IDs and matching user tool-result IDs. Child files carry agent IDs. Parent tool results can contain the agent ID. A whole line can contain several display blocks. Unknown administrative records cannot safely be treated as speech. The documented CLI retention default is 30 days. [Claude Code settings](https://code.claude.com/docs/en/settings-reference#cleanupperioddays)
- **Codex.** Local rollouts contain both response items and user/agent events, function/custom tool calls and outputs, context, reasoning and accounting records. Keep a single source of displayed speech per turn, with a fallback for event-only data. Tool results pair by call ID. [Codex rollout fixtures](https://github.com/openai/codex/blob/main/codex-rs/app-server/tests/common/rollout.rs)
- **Grok Build.** Local chat history has typed records, tool calls and tool results. Sampled chat records lack wall-clock timestamps. Updates have timestamps and nested ACP updates. Summary contains session identity, cwd and creation time. Use canonical chat order; only attach update times where linkage is unambiguous. Retain unknown message time as null. [Grok session persistence](https://github.com/xai-org/grok-build/blob/main/crates/codegen/xai-grok-pager/docs/user-guide/17-sessions.md)
- **pi.** No historical JSONL was present under the configured default session root. The installed pi 1.4.0 SessionManager wrote a synthetic v3 file with a session header, user message and two assistant siblings sharing the same parent. The official format also documents v1 linear and v2 tree files. [pi session format](https://pi.dev/docs/latest/session-format)
- **Performance.** A planning spike used Playwright 1.63 (Node binding), cached headless Chromium, a moving 24-line synthetic window, 600 individual transparent PNG screenshots and one streaming FFmpeg 8.0.1 process. Browser startup through encoder flush and browser close took **61.27 s** on the reference workstation. Output was 600 frames / 20.000 s / 30 fps, 629,356,635 bytes. This is a baseline for the method. Task 5 repeats it using the shipped Python path and all shot modes.
- **Codecs.** FFmpeg `prores_ks -profile:v 4444 -pix_fmt yuva444p10le -alpha_bits 16` produced `ap4h`, one video stream, decoded `yuva444p12le`. Decoding the alpha plane to gray recovered **0 / 128 / 255** at transparent, half-alpha and opaque sample points. An independent 4K encode reported `DNXHR HQ`, `yuv422p`, 3840×2160. The vendor matrix lists both formats in the Linux decode column. Actual Resolve Free import and edge appearance require a timeline check. [Blackmagic Design, Resolve 21.1 codec list, p. 13](https://documents.blackmagicdesign.com/SupportNotes/DaVinci_Resolve_21_Supported_Codec_List.pdf#page=13)
- **Alignment.** The backend supports `word_timestamps=True`, a converted local model directory and `local_files_only=True`. Package it as an extra, use CPU/int8 as the baseline, and check a complete local model including tokenizer before decoding. Narration accuracy remains a private acceptance test. [faster-whisper API](https://github.com/SYSTRAN/faster-whisper/blob/master/faster_whisper/transcribe.py)

## Files and boundaries

Under `src/agent_retake/`, `cli.py` dispatches to the modules below. `model.py` owns conversation records, `storyboard.py` owns YAML and selectors, `scan.py` owns detection/decision coverage, `scene.py` produces the sanitized render input, `timing.py` owns shot durations, `align.py` owns cue matching. `parsers/` has one module per harness. `render/` owns capture, encoding and packaged HTML/JS/CSS assets. Use one typed definition per file format, with an explicit schema version, and generate CLI examples/fixtures against those definitions.

`tests/fixtures/<harness>/` contains invented recordings. `tests/` runs on temporary directories without harness accounts, credentials or a GPU. Package configuration, lockfile, agent instructions, CI and a shared operator skill live at project level. Every generated file has a predictable destination, writes through a sibling temporary and is published only after validation. Serialize writers to the same output directory or refuse a concurrent conflicting run. No service or database is needed.

For example, these assertions belong in the normal command-level tests (the helper runs the installed CLI against a temporary episode):

```python
assert run_cli("preview", unreviewed_board, "--beat", "1", "--html").returncode != 0
assert list(preview_dir.iterdir()) == []
assert set(alpha_samples) == {0, 128, 255}  # controlled test patches, decoded as gray
assert abs(frame_count / fps - (beat.end - beat.start)) <= 1 / fps
```

## Task 2. Redaction before visual output

- [ ] In `tests/test_scan.py`, use invented secrets across nested tools, child messages, titles and highlights. Test all detector families, deleted rule, changed bundle, wrong version, empty scan, unreviewed keep, overlapping literals, replacement containing an original and idempotent rescans. Run `uv run pytest tests/test_scan.py` and observe missing behavior.
- [ ] Implement `scan.find_hits(conversation, visible_fields) -> list[Hit]`, `scene.prepare_scene(storyboard, bundle_bytes) -> SafeScene`. `retake scan BOARD` writes current scan_version, SHA-256 of the exact sessions.json bytes and a complete proposed rules block with reviewed=false. The single-bundle form uses the file digest directly; for multiple inputs bind ordered file digests unambiguously. Include visible beat titles and highlights in the scan; bind review to visible inputs and decisions so edits to them require a new review. Preserve applicable judgment rules on rescans. Use stable finding IDs, literal matches, deterministic longest-match substitution and collision-free plausible replacements.
- [ ] Detect API keys/tokens, email, IPv4/IPv6, user home paths, hostnames, long hex/base64 strings, cloud account IDs and phone numbers. Preserve provider prefix and length where safe. Require replacement or explicit keep with reason and reviewed=true. Independently enumerate expected findings at prepare time and report all unresolved IDs/locations without printing their values. Scan derived text and recursively apply rules before extracting headers, summaries, activity or highlights. Cues are private aligner inputs. Exclude reasoning, hidden system context, binaries and instructions from the displayed scene.
- [ ] Test that removing a detected hit with a matching digest still fails, no raw value reaches serialized browser input and changing display fields or decisions invalidates review. The review operation should be doable by an agent after operator approval (e.g. `retake scan BOARD --review` validates choices and records the review digest). Make the default scan output safe to version: put raw literals in a private sidecar next to sessions.json, store rule IDs, replacements/keep and reasons in the storyboard, and support inline matches for explicitly private boards. Treat reasons, highlights and cue text as editorial data requiring a separate check before an episode board is shared. Verify negative cases exit nonzero before output creation. Commit the green slice.
